# X Marketplace

A Next.js app that adds marketplace functionality for X (Twitter) users.

## Features (MVP)
- Sign in with X
- Browse mock listings
- Structure ready for real listings, payments (Stripe / X Money), and posting to X

## Setup
1. Clone the repo
2. `npm install`
3. Copy `.env.example` to `.env.local` and fill in keys
4. Create an X Developer app at console.x.com for OAuth 2.0
5. `npm run dev`
